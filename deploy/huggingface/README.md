# ACMP — Animated Comics / Manga / Manhwa Panels

Upload comic/manga pages (or a PDF), preview the detected panels, and render a
9:16 motion-comic video — right in the browser.

This Space runs the **no-AI (Ken Burns) pipeline** so it fits the free CPU tier.
The full project (AI animation with Wan VACE, LLM scene analysis, REST API,
trained YOLO panel detector) lives on GitHub: <https://github.com/vc-tr/acmp>.
